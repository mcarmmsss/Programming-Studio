# Programming Studio

A beginner-friendly interior design programming report builder for Paper 1.

## Project purpose
This app helps you organize your interior design user profile and future research materials in a clean, visual workspace. The project is designed to be easy to understand, easy to expand, and easy to save in the browser.

## Phase 1 included
- Project dashboard layout
- Sidebar navigation
- Modern interior-design inspired styling
- User profile form with common interior design inputs
- Auto-save using localStorage
- Manual save button
- Reset project button
- Progress tracker

## Run locally
1. Open the project folder in VS Code.
2. Start a simple local web server from the project folder:
   ```bash
   python -m http.server 8000
   ```
3. Open the browser to http://localhost:8000

## Files
- `index.html` – app layout and structure
- `styles.css` – design and responsive layout
- `app.js` – form logic, localStorage saving, and progress tracking

## Notes
This is intentionally a beginner-friendly foundation. More report sections can be added in later phases without rewriting the entire project.
